## 🧠 At a glance

| | |
|---|---|
| 🧭 **What** | Single-page Hugo theme based on the One-Day-Only (OneDly) project theme, with a satellite-projects page and Bootstrap styling |
| 🕰️ **Last change** | 2021-02-12 |

## 🚀 Use it

```bash
cd your-hugo-site/themes && git clone https://github.com/brainlife/brainlife.hugo.theme
# config.toml: theme = "brainlife.hugo.theme"
```

An example site is in `exampleSite/`.
